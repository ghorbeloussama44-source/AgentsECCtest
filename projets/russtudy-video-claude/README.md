# Vidéo motion design RusStudy (10 s), version Claude seul

Même brief que `../russtudy-video/`, fait entièrement par Claude, sans délégation à Dialagram,
pour comparer les deux méthodes.

- `russtudy-10s-claude.mp4` : 1080×1920, 30 i/s, 10,00 s, H.264, muette.
- `anim.html` : animation canvas, `window.renderAt(t)` déterministe.
- `render.py` : rendu image par image (Playwright + police Space Grotesk `sg-500.woff2`).
- `apercu.jpg` : une image par seconde.

Scènes : accroche sur grille en perspective (0–1,9 s), parcours Tunis → Russie en 5 étapes
(1,9–6,25 s), chiffres +1 200 / 40+ / dès 2 200 € (6,25–8,25 s), appel à l'action (8,25–10 s).
Textes et chiffres repris de russieetudes.com.
