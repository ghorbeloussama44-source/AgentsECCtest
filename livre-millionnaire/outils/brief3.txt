Environnement disponible : reportlab 5.0.1 (seule bibliothèque PDF à utiliser), pypdf, bibliothèque standard. Polices : utiliser les polices TTF DejaVu si présentes (/usr/share/fonts/truetype/dejavu/DejaVuSerif.ttf, DejaVuSerif-Bold.ttf, DejaVuSerif-Italic.ttf, DejaVuSerif-BoldItalic.ttf, DejaVuSans.ttf, DejaVuSans-Bold.ttf) pour gérer les accents français ; sinon repli sur Times-Roman.
Entrées : plan.json ({"titre","sous_titre","bibliographie":[{"auteur","titre","annee","idee","apport"}],"parties":[{"titre","chapitres":[{"numero","titre",...}]}]}) et dossier chapitres/ contenant 00_introduction.md, ch01.md … ch40.md, 99_conclusion.md (Markdown : #, ##, ###, ####, paragraphes, listes - / * / 1., **gras**, *italique*, > citations, ---, tableaux | simples).
Sortie : livre.pdf, format A5 (148×210 mm), marges ~18 mm, corps 10.5 pt interligné ~14 pt, texte justifié, numéros de page en pied de page, titre courant en en-tête.
Structure : page de titre (titre, sous-titre, mention « Rédigé par Qwen 3.8 Max Thinking via Dialagram »), page d'avertissement (contenu éducatif, pas un conseil financier personnalisé), table des matières automatique avec numéros de page (reportlab TableOfContents + multiBuild), introduction, puis pour chaque partie une page de titre de partie suivie de ses chapitres (chaque chapitre commence sur une nouvelle page), conclusion, puis une annexe « Bibliographie commentée » générée à partir de plan.json.
Conversion Markdown → flowables reportlab robuste : échapper &, <, > avant d'appliquer gras/italique ; ignorer les blocs de code ``` ; supprimer d'éventuelles balises de raisonnement <think>…</think> ; ne pas planter sur une ligne mal formée.
Objectif : environ 500 pages. Le script affiche à la fin le nombre de pages (via pypdf). Ajoute une option --corps (taille de police, défaut 10.5) pour ajuster la pagination vers 500 pages.
Usage : python3 mise_en_page.py plan.json chapitres livre.pdf [--corps 10.5]
